01 / SCALE

4px 主刻度

所有区域级留白回到 4 的倍数；2px 只用于工具轨迹内部和图标光学校正。

02 / PROXIMITY

外松内紧

工具之间 2px，回合内部 8–12px，回合之间 24px。距离直接表达归属。

03 / ANCHOR

一条左锚线

顶栏标题、助手头像、输入卡共用内容轨道起点，扫视时不再来回找对齐。

04 / CHROME

悬停只占一行

时间、token、复制和更多合并为 24px 尾部行，不再为隐形操作预留两行高度。

Token 对照表

当前已由 AppShell、ChatPanel、MessageList、ChatComposer 消费这些数值；后续主题化时再把重复值收敛为布局 token。

Token / 区域 当前 优化后 理由
--shell-gutter窗口外边距 10px 16px 与 8px 网格和桌面外缘留白一致。
--sidebar-width侧栏宽度 266px clamp(232px, 20vw, 296px) 1360 窗口约 272px；上下限保证小窗可用、大窗不失控。
--sidebar-pad侧栏内边距 10px 12px 与外壳、搜索下距保持同一模数。
--session-row-h / gap会话行节奏 44 / 2px 40 / 4px 行距翻倍，扫读分组更清楚。
--search-h搜索框高度 32px 36px 与 36px 工具按钮统一，点击目标更稳。
--chat-header-pad-x顶栏水平内距 20px 24px 标题对齐内容轨道，而不是主区边缘。
--conversation-track会话轨道上限 1024px 1024px 保持整页骨架，只收窄阅读列。
--conversation-pad-x轨道水平内距 clamp(16, 2.2vw, 28) 24px 桌面稳定值，减少视口变化带来的漂移。
--reading-width助手阅读列 928px 864px 中文行长约 57 字，回到舒适阅读区间。
--user-bubble-max用户气泡上限 736px 672px 和阅读列同步收窄，避免长句横冲。
--message-gap消息行垂直间距 16px 24px 回合之间明确断开，回合内部保持紧凑。
--tool-row-h / gap工具轨迹行距 26 / 4px 28 / 2px 外松内紧：行高略增，行距减半。
--tool-group-pad工具组外距 0 8px 把四行工具从摘要和正文中分离出来。
--turn-tail-h回合尾部 54px（两行） 24px（单行） metrics、时间、操作并排，去掉隐形预留。
--composer-pad-y输入区外距 14 / 20px 16 / 24px 上下留白大于内部间距，形成独立工作台。
--composer-card-pad输入卡内距 13 / 14 / 10px 14 / 16 / 12px 输入、工具栏、卡片边缘三层分离。
--composer-action发送键尺寸 32px 36px 主操作更稳，和 36px 工具栏高度对齐。
--dock-offset / width浮动栏几何 12 / 40px 16 / 44px 离边更远，胶囊内部也有呼吸。
--rail-reserve右侧内容避让 48px 64px 内容、滚动条、浮动栏三层不再互相压缩。

已按这套节奏落到生产。

落地顺序为“外壳 → 顶栏/轨道 → 消息尾部 → 输入区 → 浮动栏”。生产构建通过，1440 与 1280 宽度下已复核标题、助手头像、输入卡的同一条左锚线；此页保留为后续调整的对照基线。

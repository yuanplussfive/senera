# Model provider icons

This directory contains a curated, vendored subset of the static SVG assets
from [Lobe Icons](https://github.com/lobehub/lobe-icons), distributed under the
MIT license. The source snapshot used for the current additions is
`@lobehub/icons-static-svg@1.94.0`.

Senera does not install `@lobehub/icons` at runtime. The SVG files are bundled
with the frontend and selected through the local model catalogue rules.

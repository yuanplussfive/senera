# Tool Observation Compression

Tool result persistence and model-context sizing are separate responsibilities. The Artifact recorder stores the complete redacted result and its evidence before the Pi bridge builds the observation for the next model request. Source-view reads keep their existing Artifact coordinates and are not published as nested Artifacts.

The output schema may declare `x-senera-model-output: { "omit": ["/diagnostics", "/items/*/revision"] }`. These are package-owned JSON Pointer patterns for fields retained in the saved result but excluded from model context. Registration validates each path against the output schema; root removal and array-entry removal are rejected. Projection preserves array positions and never mutates the stored result. The same projection runs before token selection and observation sizing, and tool discovery omits hidden root fields from its return description.

Evidence records carry producer-owned provenance: `result` means facts derived from the result, while `supplement` means independent adapter content or a materialized asset. Result-derived evidence is omitted whenever a result was supplied, including null, empty values and a view made empty by field visibility rules. A hidden field cannot return through its derived evidence. Supplemental content and historical evidence without provenance remain visible. Exact MCP text copies of structured JSON are marked as result-derived by value equality before media materialization; independent text and media remain supplemental. Standard MCP text without a structured result appears once in the ordered content blocks, while declared evidence supplies the tool-card preview. Evidence deferred by the token budget is reported as an omission, with retrieval coordinates preserved. A pressure observation never embeds the deferred evidence bodies, including when its allocation is zero. The bundle URI remains available for exact reads of the original result and its diagnostic fields. Process feedback excludes absent transport values while preserving exit codes and actual output.

Only an explicit tool perception declaration adds a perception sentence, and its input is the same model result after field projection. An omitted diagnostic field cannot return through an automatically inferred sentence.

## Budget

Each Pi turn tracks the provider-reported context usage and estimates context Pi has not measured yet. The usable input capacity is the model context window minus the configured output reserve, less occupied input. A parallel tool batch shares its remaining capacity across the calls registered in that batch. The shared token-budget owner applies the configured observation ceiling while creating each reservation, keeps the raw batch allocation for diagnostics, and passes one effective `observationBudgetTokens` value to the compressor. The compressor has no second global ceiling.

The compressor counts the complete serialized observation with the active model tokenizer. This includes the protocol envelope, status, numeric and boolean fields, Artifact/evidence coordinates, and result content; it measures what the model will actually receive rather than estimating only selected JSON values.

The shared observation envelope keeps typed failure identity and a bounded message at the top level. Extended diagnostics and details enter `detail.error_detail` and share the content budget with result and process data. A shortened message declares `/error/message` as deferred; its original remains in the diagnostic source. Error structure descriptors point to `part: "outcome"`, path `/assessment/error`, so exact messages and diagnostics remain readable through the existing resource URI. Unexpected view failures use the same pressure builder and cannot reintroduce unbounded error payloads or change the execution outcome. If the mandatory protocol and protected coordinates alone exceed the allocation, their minimum valid envelope remains available for Pi's compaction boundary.

## Compression Path

1. **Verbatim**: apply the output schema's model view, then pass the complete observation unchanged if it fits the reservation. Contract visibility does not mark content as truncated; missing source content does.
2. **Structure**: an oversized durable result exposes bounded JSON outlines for both result and process output, retaining small values and describing deferred fields by exact JSON Pointer, type and token count. Incomplete objects expose `fields`, arrays expose `items`, and both report omitted counts. Descriptor pointers refer to the source, never to those presentation containers. It carries the bundle's `senera://resource/<six-character-id>` coordinate. This stage makes no model request and does not reuse an earlier task's summary. Deferred process streams mark the observation incomplete even when the result itself fits.
3. **Selection**: `ArtifactReadTool` accepts `requests: [{ uri, part?, paths?, view? }]`. No paths returns the structure; an array of RFC 6901 pointers returns selected values. An empty pointer, or explicit `view: "content"` without paths, selects the whole part. Use `view: "structure"` with paths to inspect nested subtrees. Existing outlines are structurally rebudgeted without summarization, preserving source paths and measurements. Available parts and selection errors remain explicit, including on failed reads of a known manifest. The `process` part shares integrity-verified stdout/stderr reconstruction with historical full reads; `outcome` reads the saved execution, assessment and output status, including exact failure diagnostics. Selection compression reserves space for accompanying process and diagnostic feedback, and preserves it in the returned observation. Reads are SourceViews and never publish nested result bundles.
4. **Selected content compression**: exact selected values that fit remain unchanged. Small selections are allocated first so their unused share remains available for larger fields. Oversized values use the existing Pi summary request first, then the shared mechanical content pipeline, then structural truncation if necessary. Each selection reports `representation`, `method` and `complete`; provider rejection reports its degradation reason while preserving the tool outcome. Input capacity for the summary model is separate from the desired summary length, so summarization can inspect the selected source. Cancellation is propagated, and late summary or mechanical results after cancellation are discarded.

The HTTP inspector uses the same integrity-verified reader and receives original selected values. Model token limits apply in the Pi observation layer, not to the disk source or inspector. Results without a durable source use the same compression stages directly. Protected Artifact/evidence coordinates remain in the observation envelope. An unexpected observation projection error is a view failure and never rewrites a completed execution as a failed action.

Tool packages declare field visibility, while the host owns token budgets and compression. If the mandatory protocol and protected coordinates consume the entire Pi reservation, the compressor returns a bounded pressure observation that points to the durable Artifact when one exists; it does not turn a successful tool execution into an oversized result or a synthetic execution failure.

## Extension Contract

System Tool packages define input and output contracts, execution policy, search metadata, and artifact policy. Model visibility is part of that output schema, rather than a separate projection file or a host list of tool and field names. MCP output continues to use the standard `tools/list`, `content`, and `structuredContent` boundary and may declare the same schema annotation. Both sources enter the same host-owned observation compressor. A schema without an annotation preserves all its fields.

MemoryRecall retains identity, revision, ranking and learning metrics internally, while returning one content body, type and occurrence time per record. Its selection budget measures this declared model view; the learning ledger still receives the native identity and full revision. MemoryWrite returns its acceptance status without repeating the submitted summary; the complete intent remains saved for deferred learning. Image analysis excludes the input prompt echo, model name and file hashes. Document extraction exposes one requested Markdown or text view with an explicit truncation flag; alternate previews and chunks remain readable from the original saved result. Resource lookup and WebFetch preserve actionable paths, URLs and truncation state while excluding checksums and render diagnostics from the default observation.

## Public Reading Feeds

- Prefer a source's own RSS or Atom feed when available.
- For Chinese technical updates, start with 少数派 RSS, HelloGitHub, and 阮一峰科技周刊.
- For a particular blog or project, inspect its public `feed`, `rss`, `atom`, release, or changelog page before using a general news site.

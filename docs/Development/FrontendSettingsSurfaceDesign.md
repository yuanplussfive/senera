# 设置目录与详情页

继承 [Hira 的 PR #152](https://github.com/yuanplussfive/senera/pull/152) 中的间距、邻近归属、加载几何与图标治理原则，适配当前插件目录和工作区菜单。代码与真实组件是样式的唯一来源。

- 插件与渠道目录使用随实际容器宽度变化的网格；手机单列，宽屏并列。标记、名称、两行介绍和启用开关构成一个条目，用留白与轻分隔表达归属，不增加整张卡片外壳。
- 目录和详情的身份标记使用有边界的图标容器；工具行仍用小号无框标记。语义图标跟随主题，真实平台品牌保持原始形状，不按插件名称猜图标，不另建前端插件映射。来源见 `PluginBrandAssets.md`。
- 扩展名称与介绍来自 `extension.json`；工具名称、操作名和完整说明来自 `.tool.json`。面向用户的扩展介绍说明用途，工具契约保留执行要求。前端不截句重写说明。
- 详情页保持与目录一致的内容锚线。存在配置时，功能与配置使用公共 `SegmentedControl` 的下划线形式；无需配置的包直接展示能力。工具默认最多展示 4 个，用户可展开其余项；工具说明保留完整原文。
- 详情先展示用途和包声明的使用示例，再展示真实功能与配置。示例使用本地主题组件绘制，明确说明是用途示例，不伪装成已执行的结果或截图。未声明示例的第三方包不自动编造。
- 模型选择是带搜索的专用组合框，保留品牌与独立选中标记；原生思考档位由模型配置提供，使用 `MenuSelect`。审批值使用菜单单选行，说明审批策略。`@` 列表采用紧凑的名称与说明行，保留完整说明和实际激活契约。
- 所有模型搜索复用 `SearchSelect`。候选来自已启用供应商中的已配置模型，按字段声明的能力筛选（例如绘图 `ImageOutput`、识图 `Vision`），不从名称猜能力。引用模型 ID 的字段只提交候选 ID；外部 API 模型名通过显式 `allowCustom` 支持手填，选择建议不会更换 API 地址或密钥。
  模型展示由 `shared/models/ModelSelect` 统一封装；显式模型图标与继承的供应商图标优先于品牌推断。主对话底部保持纯模型名，展开候选列表才显示图标；设置表单同时展示当前图标。候选使用单行，供应商通过悬停与无障碍描述提供，并继续参与搜索。无结果时明确提示“没有匹配的模型”。嵌套浮层通过共享层级上下文递进，不在业务组件单独提高层级。
  个人和 Agent 头像共用 `shared/media/AvatarCropper` 的拖动、缩放与键盘微调，再保存裁剪结果。刷新、检查与渠道连接等工具操作复用 `IconButton`，保留名称、提示与执行状态。
  内置单色品牌图标通过资源清单声明明暗适配，彩色品牌与用户图标保留原色。头像裁剪输出 WebP，保留透明背景。
- 密钥、Token 和密码统一使用 `SecretInput`：输入框后接固定宽度的显隐区，长密钥不会覆盖按钮，不附加复制或粘贴按钮。存储密钥的清除是独立的显式操作。
- 悬停说明统一使用深色 `Tooltip`，在弹窗中继承共享的容器与层级；原生 `title` 只保留 iframe 的可访问名称等文档语义。纵向 `ScrollArea` 将内容限制在视口宽度内，能力列表的长说明在行尾省略，完整内容由 Tooltip 提供。
- 插件详情展示包内技能与系统技能中声明的工具关联，读取真实技能目录与工具声明，不从名称猜测。渠道详情复用同一技能列表。连接状态放在平台名称前，以真实运行状态驱动网络图标，与启用开关分离。
- 对话的文件变更与下载产物分开展示，变更栏提供行数、展开、审阅与撤销。整轮撤销由宿主验证各检查点、连续版本及当前文件状态后统一恢复；缺少检查点时禁用入口并说明原因，不将部分恢复视为整轮成功。
- 时间配置通过声明 `durationUnit` 使用 `DurationInput`，展示秒、分钟、小时或天；数字框与单位选择器保持同高、同字号。换算后仍按原始单位保存，切换显示单位不改配置。禁止通过字段名后缀在运行时猜单位。
- `SettingsControlRow` 统一设置锚线。普通字段使用左右布局；数组、键值与表格编辑器使用 `stacked` 布局，从标签下方的左侧内容锚线开始，占满可用宽度，不添加嵌套缩进或右侧窄栏。
- 模型选项共用 `SettingRow` 与 `SectionLabel` 的内容起点，能力开关根据实际容器宽度排布。上下文窗口使用精确 token 输入和容量尺，刻度仅依据配置值与 models.dev 目录容量计算；目录未声明时不虚构模型上限，也不限制用户输入。
- 模型能力通过语义图标区分图像理解、图像生成、推理、工具调用和 token 用量，目录摘要与编辑表单使用同一含义；用量不使用网络连接图标，价格不使用运行性能图标。
- 运行时依赖使用可展开的普通列表。版本、大小、检查时间和操作保持紧凑；路径、缓存与能力放进“安装信息”，只展示实际返回的字段，不增加空值占位表。
- 渠道条目的图标、标题与开关顶部对齐。连接状态放在平台名称前，以真实运行状态驱动网络图标，保留无障碍名称与悬停说明；目录与详情共用映射。QQ 与 Senera QQ 都使用 QQ 品牌图标；目录介绍最多两行，完整操作说明放进详情页的可展开使用说明。
- 侧栏只读取当前工作区的会话，按真实渠道字段分组；组内和组间按最近会话活动排序，同时间维持目录次序。各组默认最多 5 个对话，支持展开与收起，当前对话保持可见；搜索和批量选择展示全部匹配项，后台文本增量不刷新侧栏。
- 渠道标题、对话和展开动作共用同一图标列与文字起点；不使用长竖线或逐层缩进。选中背景占整行，桌面行高紧凑，触屏通过公共响应能力保持点击高度。状态图标有固定位置，思考或错误状态不推动标题左右跳动。
- 渠道标题可通过鼠标或键盘折叠整组对话，计数使用居中圆形徽标，与图标和名称同轴。整组折叠与“显示更多”独立，重新打开保留原来的显示数量；搜索与批量选择时展开全部匹配项，退出后恢复用户原来的折叠状态。收展复用 `MotionDisclosure`，关闭内容不可点击或进入键盘焦点。
- 对话列表与输入框保留独立的渲染边界；不变的历史消息沿用数据引用和投影缓存，事件导航在首屏内容之后调度。历史回合折叠详情使用 `MotionDisclosure.lazyMount` 首次展开挂载，之后保留交互状态与收起动画；不通过保留所有会话的隐藏界面来换取切换速度。
- 工具详情展开时自动读取完整归档结果，读取期间显示加载状态，失败时才提供重试；切换工具或工作区时取消旧请求。运行标题和诊断列表共用输入摘要，纯附件消息展示图片与文件数量，原始用户正文保持不变，历史恢复保留附件信息。
- 工作区菜单先显示当前工作区，再切换文件与工作区列表。路径、选中状态和危险操作分层表达；触摸和键盘操作不依赖悬停。
- 加载态保留表单、双栏或目录的真实结构，复用 `SettingsSectionLoading`。新增外观变体同步 Story，不复制生产样式。
- 复核 `390px`、`900px`、`1280px`、`1440px`、`1600px` 的明暗主题、滚轮、键盘与内容溢出。布局数值不另加几何测试。

关键实现：`PluginsSection`、`SystemToolsSection`、`PluginIdentityIcon`、`WorkspaceMenu` 与共享选择控件。扩展描述与图标应在所属清单中维护。

# Research Primary Sources

## Define The Evidence Need

- Convert the question into a small set of claims that must be verified.
- Prefer official specifications, maintainers' documentation, source code, release notes, and peer-reviewed work. Use secondary material only to locate or contrast primary evidence.
- Check the source's date, version, platform, and applicability before using it.

## Synthesize Carefully

- Compare sources directly when they answer the same claim.
- Separate source-backed facts, engineering interpretation, and uncertainty.
- Explain practical implications for Senera, including integration boundary, operational cost, and failure modes.
- When a source cannot be reached, say so and do not replace the missing fact with a confident guess.

## Stop And Report

Stop when the available evidence supports the decision or clearly shows what remains unverified. Return ordinary text with the answer, source links or references, relevant versions, implications, and remaining gaps. Do not broaden research after it stops changing the recommendation.

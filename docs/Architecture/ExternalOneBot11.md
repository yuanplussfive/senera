# OneBot 11 渠道

在「设置 → 渠道 → OneBot 11」填写服务地址、令牌和主人 QQ 号，然后启用。
支持 SnowLuma 等提供正向 OneBot 11 接口的服务。Senera QQ 是独立的本地客户端入口，
两者各自启停，共用宿主的会话、附件和消息队列。

对应配置位于 `Extensions.agent-channels.Configuration`：

```json
{
  "enabled": true,
  "onebot": {
    "enabled": true,
    "wsUrl": "ws://127.0.0.1:3001",
    "wsToken": "replace-with-token",
    "ownerQq": "987654321",
    "groupAllowedUsers": ["876543210"]
  }
}
```

地址、令牌和 QQ 号替换为实际值。机器人账号由网关登录信息核验；主人 QQ 填操作者账号，
不能填写机器人的账号。

## 主人与接入范围

`ownerQq` 是本渠道的 root 用户，可以执行群会话的 `/new`、`/stop`、`/steer`。
宿主把主人账号注入系统提示词，模型按每条消息的真实发送者区分主人和其他人。
昵称、自称、引用和转发不能授予主人权限。主人配置不合并用户记忆，也不绕过工具审批。
未填写时，不设置渠道主人。

主人可以直接私聊；其他用户填入 `allowedUsers`，群号填入 `groupAllowedUsers`。
需要开放所有用户和群时启用 `allowAllUsers`。可用 `commandUsers` 另授予群控制命令权限；
私聊用户仍可以管理自己的私聊会话。群白名单本身不授予管理权限。

## 高级设置

- 默认通过 WebSocket 收发。只提供事件的 WebSocket 端点需选择 HTTP 动作，另填
  `httpUrl`、`httpToken`。两套令牌独立保存，不互相替代。
- `expectedSelfId` 可限定机器人 QQ，账号不符拒绝连接。更换账号会隔离旧会话与待发消息。
- `requestTimeoutMs` 控制动作等待和探活周期。断线按配置的重连间隔退避。
- 文件消息扩展 `fileMessages` 和戳一戳扩展 `poke` 默认关闭，按网关实际能力开启。

图片、语音、视频使用标准消息段。宿主文件先转为网关可读的字节，群文件通知通过网关
接口取得下载地址，私聊离线文件使用通知 URL。媒体仍经过统一附件导入和发送链路。
任意文件发送要求网关支持内联文件消息，不能把 Senera 本机路径当作远程网关路径。

消息先持久接收，再处理附件；发送复用持久队列。超时或断线后无法确认发送结果的消息
标为结果未知，不自动重复发送。设置页显示渠道连接状态及已核验的机器人账号。

# Frontend Experience Inspection

1. Locate the component, state source, event flow, styles, and parent layout before editing.
2. Distinguish document flow, overlay, scroll-container, data-calculation, and refresh problems.
3. Check loading, success, error, empty, disabled, responsive, and overflow states.
4. Preserve accessible interaction and stable element dimensions.
5. Verify component behavior with focused tests and inspect rendered desktop and mobile views when visual risk exists.

Use ToolSearch to locate workspace and browser verification tools when needed.

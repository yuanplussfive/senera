# Execute Delegated Task

## Own The Assignment

- Restate the requested outcome, scope, access mode, and acceptance condition before acting.
- Choose only the work phases needed for that outcome: inspect, decide, implement, or verify.
- Treat the supervisor's task and host policy as authoritative. Ask the supervisor only when available evidence cannot resolve a decision that changes the result.

## Coordinate Without Duplication

- Do not repeat work that the supervisor or another child owns.
- If independent descendant work is genuinely necessary and the host exposes delegation, give each descendant a bounded task with its own evidence and completion need; otherwise continue the assigned work directly.
- Reconcile returned evidence before using it and close or stop no-longer-needed descendants.

## Finish Clearly

Stop when the acceptance condition is met or the remaining blocker is explicit. Return ordinary text addressed to the supervisor: outcome, material evidence, files or decisions affected, verification, and unresolved risk. Do not emit a host-specific JSON envelope or leave the supervisor guessing whether the assignment is complete.
